StudyBuddy: Local AI Learning Assistant

  • Tech Stack: Python, Streamlit, Ollama (Llama 2, Mistral, DeepSeek-R1), SQLite
  • Github URL: Project Link

Developed StudyBuddy, a privacy-first AI tutor designed to guide students through course materials using a Socratic questioning approach.

The system processes PDFs locally via Ollama, ensuring that student data never leaves the device while providing features like automated summarization and interactive MCQ generation.

Implemented a tiered learning logic that encourages deep reasoning, supported by a local SQLite database to persist learning progress and session history.
