🎥 Video Face Detection & Age-Based Anonymization

  • Core Tech: Python, MTCNN (FaceNet-PyTorch), DeepFace, OpenCV, CUDA
  • Functionality: Automated Face Detection & Selective Age-Based Blurring

Developed a specialized Privacy Protection tool that processes video files frame by frame to identify and anonymize sensitive content. The system utilizes a dual-model pipeline to ensure high accuracy in both detection and attribute analysis.

The application integrates MTCNN for robust face detection and DeepFace for real-time age estimation. By implementing a configurable CHILD_AGE_THRESHOLD, the tool automatically applies a Gaussian blur to individuals predicted to be below the specified age, ensuring digital privacy compliance.

Optimized for performance, the script features CUDA acceleration for GPU-enabled systems while maintaining graceful error handling to ensure continuous processing even during complex detection failures.


Technical Workflow

  • Face Detection: Precise localization using MTCNN landmarks.
  • Age Estimation: Biological age prediction via DeepFace neural networks.
  • Privacy Guard: Conditional blurring based on age thresholds.
  • Output: Real-time console progress and final MP4 reconstruction.
