NoveltyAI: Recursive Research Assistant via LLM

  • Tech Stack: Python, Streamlit, Ollama, Llama 3.1, DuckDuckGo Search API
  • Github URL: Project Link

Developed NoveltyAI, a Streamlit-based recursive research assistant designed to help researchers transform initial concepts into publication-ready proposals through an automated, iterative loop.

Integrated local Large Language Models (LLMs) via Ollama, specifically utilizing Llama 3.1 to evaluate research novelty, detect conflicts with existing literature, and automatically refine proposals until a unique research angle is identified.

Implemented an automated literature scanning pipeline using the DuckDuckGo Search API to perform targeted academic queries, providing the AI with real-time context to verify the originality of user-submitted ideas or uploaded PDF concept papers.
