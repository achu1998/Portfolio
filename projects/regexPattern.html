Web Application for Regex Pattern Matching and Replacement Using LLM

  • Tech Stack: Python, Django, React, Node.js, Ollama, LLMs (Mistral, Google/flan-t5-large)
  • Github URL: Project Link

Created a full-stack web application featuring a Django backend and React frontend that allows users to upload Excel or CSV files and seamlessly perform data replacement tasks via an intuitive user interface.

Integrated local Large Language Models (LLMs) via Ollama, utilizing Mistral to translate natural language instructions into precise regex patterns, alongside google/flan-t5-large for accurately extracting and verifying target replacement values.

Developed an interactive preview mechanism that displays the generated regex output and visually highlights the resulting modifications in a tabular format before the user finalizes the replacement actions.
