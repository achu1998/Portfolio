AI Marker: Local Automated Grading Assistant

  • Tech Stack: Python, Streamlit, Ollama, Llama 3.1, Llama 3.2 Vision
  • Github URL: Project Link

Developed AI Marker, a privacy-first Streamlit application designed for university teachers to perform AI-assisted grading without compromising student data privacy.

Integrated local Large Language Models (LLMs) via Ollama, utilizing Llama 3.1 for rubric-based grading and Llama 3.2 Vision for handwriting recognition (OCR) of scanned student answer sheets.

Implemented an end-to-end offline pipeline that structures evaluation criteria, generates detailed strengths/weaknesses feedback, and produces professional PDF reports while maintaining full FERPA (privacy protection of student education records) compliance through local data processing.
